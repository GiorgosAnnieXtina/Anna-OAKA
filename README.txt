SONG PWA WITH BUILT-IN ADMIN

The app now includes a gear button (⚙) on the homepage.
Tap it to:
- add songs
- edit songs
- delete songs
- download the updated songs.json

To publish changes:
1. Open the app and tap ⚙.
2. Add/edit songs.
3. Tap "Download songs.json".
4. Replace songs.json in the GitHub repository.
5. Wait for GitHub Pages to publish.
6. Refresh the app on the phone.

No code editing is required.
